Detects values that systemd accepts but warns about when it loads the unit.

Examples are obsolete spellings that systemd rewrites (StandardOutput=syslog, paths below /var/run/), settings systemd calls unsafe (KillMode=none, User=nobody), and values it silently corrects (an address without a prefix length, a WireGuard AllowedIPs= entry with host bits set). Each message says what systemd does with the value and what to write instead.
