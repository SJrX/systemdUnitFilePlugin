Suggests rewriting an IPv6 address in its canonical form (RFC 5952).

systemd accepts any valid spelling of an IPv6 address. The canonical form writes the same address in exactly one way, so it is easier to compare and search for: hex digits in lower case, no leading zeros in a group, and the longest run of two or more zero groups shortened to ::. For example, 2001:0DB8:0000:0000:0000:0000:0000:0001 becomes 2001:db8::1.

Addresses with an embedded IPv4 part, such as ::ffff:192.0.2.1, are left alone.

This inspection needs the new grammar engine, which you turn on under Settings | Tools | systemd Unit Files.
