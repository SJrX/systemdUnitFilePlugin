Suggests rewriting a MAC address in the format chosen under Settings | Tools | systemd Unit Files.

systemd accepts a MAC address written several ways, for example 00:1a:2b:3c:4d:5e, 00-1A-2B-3C-4D-5E and 001a.2b3c.4d5e. This inspection flags any MAC address not written in the preferred format and offers to convert it. If the address is already written in one of the other formats, it also offers to make that format the preferred one.

Set the preferred format to Leave as written to turn the suggestions off. Other hardware addresses, such as Infiniband addresses in [Match] sections, are left alone.

This inspection needs the new grammar engine, which you turn on under Settings | Tools | systemd Unit Files.
